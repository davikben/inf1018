1.a)
Ao rodar, o dump e a main, obtive 4 linhas printadas. A primeira parte de cada linha é aleatória (com exceção dos úlitmos 4 números que são sucessor do anterior por estarem um do lado do outro na memória), já a segunda parte é sempre:
10
27
00
00
Isso são os valores em cada byte do int. Um int tem 4 bytes, por isso temos 4 linhas.
Esses bytes estão armazenados do menor byte para o maior (little-endian).
Ao converter isso para decimal:
10 27 -> 27 10 (ORDEM QUE LEMOS) -> (2 * 16^3) + (7 * 16^2) + (1 * 16^1) + (0 * 16^0) = 8192 + 1792 + 16 + 0 = 10.000

2.c)
agora, a cada caractere há uma verificação para determinar se é um digito ou não:
if(isdigit(*s) == 0) // é digito
    a = a*base + (*s - 'a' + 10);
*s - 'a' serve a mesma lógica do *s - '0', enquanto o +10 serve para ajustar na posição correta na base.
Por exemplo, o caractere 'b' representa o número 11.
'b' (98) - 'a' (97) = 1
1 + 10 = 11

A maior base que podemos representar com esse esquema é a base 36.
